# Code of Conduct

Fast Sub contributors are expected to keep discussion focused, respectful, and useful.

## Expected Behavior

- Be direct, constructive, and specific.
- Assume good intent, but do not ignore security, privacy, or correctness problems.
- Keep issue reports and reviews grounded in reproducible behavior.
- Respect user privacy. Do not request or post raw API keys, ready tokens, signed URLs, private media, or unredacted local paths.
- Keep disagreements technical and actionable.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing another person's private information.
- Posting secrets, private media, or credential-bearing logs.
- Repeatedly derailing issue reports, reviews, or release discussions.

## Reporting

For security issues, follow `SECURITY.md`.

For conduct issues, open a private maintainer contact path before broad public discussion when possible. If no private maintainer contact is available yet, open a minimal public issue that asks for maintainer contact without including private details.

## Enforcement

Maintainers may edit or remove comments, close issues, block participants, or restrict contribution access when behavior harms the project or its users.
