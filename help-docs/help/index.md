# Fast Sub Help

Fast Sub helps you create, translate, and burn subtitles from local media.

The help pages are organized around tasks:

| Task | Page |
| --- | --- |

## Product Principles

- Local workflows should stay local.
- Remote providers must be explicit.
- Models are installed by the user and are not bundled with the app.
- Diagnostics should explain failures without exposing secrets.
