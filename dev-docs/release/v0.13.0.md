## Signing Status

- Windows builds are unsigned. SmartScreen or antivirus reputation warnings may appear.
- macOS builds are ad-hoc signed and not notarized. Gatekeeper may block the app until the user follows the documented install steps.
- These artifacts are preview builds, not stable signed distribution builds.

## Included Runtime Components

- Electron desktop app.
- Go daemon.
- Native whisper.cpp runtime for packaged native transcription.
- App-private Python runtime for local ASR and translation bridge features.
- ASAR-outside packaged JS helper for no-key Bing/Google web translation.

The package does not include ASR or translation model weights. Models are installed after first run through the app/model store.

## Known Limitations

- Default local NLLB translation uses a model marked `CC-BY-NC-4.0`; review the model license before commercial or organizational use.
- Windows code signing and macOS Developer ID notarization are not configured yet.
- Real OpenAI provider smoke is not part of the default automated test suite.
- Bing/Google web translation is experimental and best-effort. Windows x64 packaged short-SRT smoke has passed; macOS arm64 web translation smoke needs a macOS release machine.
- Package size is large because Electron/Chromium and an app-private Python AI runtime are bundled.

## Validation

- `master` branch protection requires up-to-date `Go`, `Python`, and `Desktop` checks before merging protected changes.
- The Windows package build was produced after commit `af07626`.
- `npm run package` completed on Windows.
- `npm run smoke:packaged` passed against the packaged Windows app.
- `npm run smoke:web-translation` passed against the packaged Windows app for `web-bing` and `web-google` using a short public SRT and no API key.
- Release smoke and checklist records live in `desktop-tests/round13-release-smoke.md` and `desktop-tests/round13-release-checklist.md`.
